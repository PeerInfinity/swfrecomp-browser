# SWFRecomp build bundle

This folder was produced by the in-browser SWFRecomp page. It contains
everything needed to build the recompiled SWF into a browser WASM page with
WebGPU graphics, without a checkout of the SWFRecomp repository.

## Contents

| Path | What it is |
|---|---|
| `<name>.swf`, `config.toml` | the SWF you dropped and the recompiler config used |
| `RecompiledTags/`, `RecompiledScripts/` | C generated by SWFRecomp (timeline tags, ActionScript) |
| `RecompiledABC/` | present only for AS3 (AVM2) SWFs |
| `recompiler.log` | the recompiler's console output |
| `runtime/` | snapshot of SWFModernRuntime sources + wrappers at the commit in `BUNDLE_INFO.json` |
| `build.sh` | the build (mirrors the repo's `build_test.sh wasm --graphics`) |

## Build

1. Install Emscripten: <https://emscripten.org/docs/getting_started/downloads.html>
2. `source /path/to/emsdk/emsdk_env.sh` (or `export EMSDK=/path/to/emsdk`)
3. `./build.sh`

Output lands in `out/`: `<name>.js`, `<name>.wasm`, `index.html`.

## Run

```
python3 -m http.server -d out 8080
```

Open <http://localhost:8080/> in Chrome (WebGPU required) and press **Run SWF**.

Environment knobs: `RT_OPT=-O0` for a fast debug build, `FRESH=1` to discard the
incremental object cache, and for AVM2 SWFs `ABC_OPT`, `MOCK_DATE_TIME`, `SWF_URL`
(see comments in `build.sh`).
